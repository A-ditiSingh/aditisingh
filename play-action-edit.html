Edit Actions
Sidebar shows suggested actions as a numbered list. The pencil icon opens a dialog to edit, reorder, or add actions.
Steps
1
Suggested Actions sidebar
Panel shows numbered actions with bold titles and descriptions. Pencil icon in header opens the edit dialog.
2
Edit dialog
Full list of actions with per-row edit (✏) and more (···) controls. "Add Action" at the bottom.
3
Add Action inline form
Clicking "+ Add Action" appends an inline form with title + description fields and confirm/dismiss buttons.
